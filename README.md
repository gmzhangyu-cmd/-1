# 轻记健康

一款用于个人健康记录的原生微信小程序。第一版数据仅保存在当前微信客户端本机，不上传服务器。

## 功能

- 记录替尔泊肽注射日期、时间、剂量、部位、批号、药品有效期和备注
- 记录每日体重、饮食营养、饮水、排便次数与 Bristol 分型
- 汇总蛋白质、碳水、脂肪和热量，并显示目标完成情况
- 查看下次计划注射日、药品到期提醒和历史记录
- 按医生或营养师建议设置个人营养目标与注射间隔，复制 JSON 数据作为手动备份

> 本工具只用于个人记录，不能替代医生诊断。用药剂量、频率以及不适处理请遵医嘱。

## 本地开发

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录。
3. 在 `project.config.json` 中将测试 AppID 替换为自己的小程序 AppID；也可先使用测试号预览。
4. 点击“编译”。本项目没有第三方依赖，不需要执行 `npm install`。

运行核心逻辑测试：

```bash
npm test
```

## 数据与隐私

数据通过 `wx.setStorageSync` 保存在本机。清理微信缓存、删除小程序或更换设备可能导致数据丢失，请定期在“设置”页复制备份。请勿在备注中记录身份证号、联系方式等不必要的敏感信息。
