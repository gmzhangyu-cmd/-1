# 轻记健康

一款粉色、简洁的原生微信小程序，用来记录个人身体变化、生活习惯和替尔泊肽相关用药信息。数据仅保存在当前微信客户端本机。

## 功能

- 每日轮换 20 条温柔激励语，配合原创启动插画淡入、缩小后进入首页
- 使用 💉 图案记录时间、剂量、部位、批号和药品有效期
- 记录体重、BMI、体脂率、腰围、臀围、大腿围和上臂围
- 查看体重、BMI、体脂率、腰围和臀围变化曲线
- 制定体重、体脂率、腰围和臀围目标
- 以早餐、午餐、晚餐的方式记录饮食，不计算热量和营养素
- 通过 100ml、300ml、500ml 和 1000ml 四种趣味水瓶记录饮水
- 记录排便次数与 Bristol 分型
- 体重下降或上升后显示短暂、温和的反馈提示
- 本机手机号注册入口与 JSON 数据复制

> 本工具只用于个人记录，不能替代医生诊断。用药剂量、频率以及不适处理请遵医嘱。

## 本地开发

1. 安装并打开微信开发者工具。
2. 选择“导入项目”，目录选择包含 `app.js`、`app.json` 和 `project.config.json` 的仓库根目录。
3. 将 `project.config.json` 中的测试 AppID 替换为自己的小程序 AppID；也可先使用测试号预览。
4. 点击“编译”。项目没有第三方依赖，不需要执行 `npm install`。

运行自动测试：

```bash
npm test
```

## 注册与隐私

当前手机号注册是本机资料登记，不发送短信验证码，也不上传手机号。正式短信验证、登录和跨设备同步需要后续接入已认证的小程序后台。清理微信缓存、删除小程序或更换设备可能导致本机数据丢失，请定期复制 JSON 数据留存。
